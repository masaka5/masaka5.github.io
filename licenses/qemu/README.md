# QEMU Wasm source materials and notices

This directory accompanies `vendor/qemu/`. Archives are served from the same site, without charge or registration. They preserve source code, build instructions, and licenses; `source-manifest.json`, `go-module-manifest.json` and `binary-sha256.json` record URLs and SHA256. These source archives are individually under 100 MB and do not require reassembly.

## Source downloads

* [Patched QEMU 8.2.0 source](qemu-wasm-source.tar.gz), ktock/qemu-wasm commit `0ef7b4e2814b231705d8371dd7997f5b72e70baf`: complete repository snapshot with QEMU source, Wasm TCG patches, Dockerfile, firmware build recipes and option ROM source.
* [Local transformations and final source](local-changes/): `extend-memory.py`, generated JavaScript patch, final qemu.js/network.js and binary manifest. Changes made 2026-11-11: 4032 MiB shared memory import, unsigned high address accesses, thread lifecycle and browser fetch network adapter. The final JS is provided as preferred editing material for the downloaded generated module; no equivalent C changes were made locally.
* [Emscripten 3.1.50](emscripten-source.tar.gz), [GLib 2.75.0](glib-source.tar.xz), [libffi](libffi-source.tar.gz), [zlib 1.3.1](zlib-source.tar.gz), [pixman 0.42.2](pixman-source.tar.gz), [PCRE2 10.40](pcre2-source.tar.bz2), [gvdb](gvdb-source.tar.gz), [dtc](dtc-source.tar.gz), [keycodemapdb](keycodemapdb-source.tar.gz).
* [SeaBIOS/SeaVGABIOS](seabios-source.tar.gz), [iPXE](ipxe-source.tar.gz), [EDK2 EfiRom tool](edk2-source.tar.gz), at QEMU's exact submodule pins. QEMU's own `pc-bios/optionrom` contains kvmvapic and linuxboot_dma sources. The ROM build configuration and commands are in QEMU `roms/Makefile`, `roms/config.*` and `pc-bios/optionrom/Makefile`.
* [container2wasm proxy source](container2wasm-source.tar.gz), commit `da372f28342f73be1857e1ab5f67eae56280b021`, referenced by QEMU's networking documentation. `extras/c2w-net-proxy` contains Go source/go.mod/go.sum; all 18 direct and indirect modules pinned by that go.mod, including replacements, are preserved in [go-modules/](go-modules/) with licenses in [texts/](texts/).
* [browser_wasi_shim 0.2.21](browser-wasi-shim-source.tgz) (MIT OR Apache-2.0), [xterm-pty 0.10.1 package](xterm-pty-source.tgz) and [TypeScript source](xterm-pty-typescript-source.tar.gz) (MIT).

License texts, copyright and NOTICE files extracted without alteration are under `texts/`, retaining their component paths. Archives retain full source headers and additional licenses. QEMU is GPL-2.0 with per-file alternatives/components; GLib and SeaVGABIOS/SeaBIOS include LGPL/GPL terms; iPXE includes GPL and its documented exceptions; Emscripten and browser_wasi_shim offer MIT/Apache alternatives; container2wasm is Apache-2.0; Go dependencies retain their own BSD/MIT/Apache and other component notices. Consult each preserved file rather than applying a single license to all components.

The browser host source [qemu-host.js](local-changes/qemu-host.js) includes an additional checked Wasm transformation at instantiation: the `pdu_complete` RLERROR field is translated from Emscripten/WASI errno numbers to Linux 9p protocol numbers. Upstream's `hw/9pfs/9p-util.h` incorrectly skips that conversion for Emscripten. The patch requires exactly one matching function body and instruction anchor; another binary revision fails explicitly. It preserves QEMU libc errno values internally. A scoped Emscripten FS chmod adapter resolves `/proc/self/fd/N` to the actual shared-file node, needed by the 9p passthrough creation path. These transformations are provided as editable JavaScript source and do not silently change the downloaded binary file.

## Build information and correspondence limits

The QEMU archive's README contains the upstream Docker build and `emconfigure`/`emmake` commands. Dockerfile pins Emscripten 3.1.50, GLib 2.75.0, zlib 1.3.1, pixman 0.42.2 and libffi `adbcf2b247696dde2667ab552cb93e0c79455c84`; GLib wrap pins PCRE2/gvdb. Upstream command enables `--static --target-list=x86_64-softmmu --cpu=wasm32 --without-default-features --enable-system --with-coroutine=fiber --enable-virtfs`, pthreads, asyncify, mimalloc, xterm-pty and 2300 MB original memory. Apply the included local transformations to the resulting module; current distributed memory import is 4032 MiB. The full upstream build has **not** been run here and byte-for-byte reproducibility is **not** claimed. Apt repositories/base-image digests and all build tools were not hermetically pinned upstream. Native LLVM/Binaryen compiler toolchains are obtained through the upstream emsdk recipe, not replicated in this source directory.

The Wasm and firmware were obtained from `https://ktock.github.io/qemu-wasm-demo/images/alpine-x86_64/`; upstream distribution did not include an authenticated exact source-build record. The above QEMU source revision is the pinned upstream repository revision used for this integration; exact correspondence between this revision and that prebuilt has not been established. The proxy source pin comes from upstream documentation, not authenticated embedded proxy build metadata. These unresolved provenance gaps mean this package must **not** be described as verified complete corresponding source or a certification of GPL compliance. Resolving them requires an upstream exact build record or building and distributing a new binary from a fully recorded source/dependency set.

ROM boundaries in `rom.bin`: bios-256k.bin `[0,262144)`, efi-virtio.rom `[262144,422912)`, kvmvapic.bin `[422912,432128)`, linuxboot_dma.bin `[432128,433664)`, vgabios-stdvga.bin `[433664,473088)`. The downloaded pack SHA256 is `15de099e1363ceb13a31b9d11836337bab974f9460836449330b20c0534d06c9`. All five ROM segments match byte-for-byte the prebuilt `pc-bios/` files in the bundled pinned QEMU source archive; see `rom-source-match.json`. SeaBIOS reports `rel-1.16.3-0-ga6ed6b701f0a-prebuilt.qemu.org`, agreeing with the bundled source submodule pin. This proves pack-to-tree identity, not a reproducible-build proof from firmware source.

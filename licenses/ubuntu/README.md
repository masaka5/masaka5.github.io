# Ubuntu Server image

This browser appliance uses the official Ubuntu 24.04 LTS Minimal cloud image root filesystem. The exact URL, SHA256, compressed/expanded sizes and guest kernel are recorded in [the image manifest](../../tools/webvm/images/ubuntu-manifest.json). The image retains its installed package database and `/usr/share/doc/*/copyright` files. [copyrights.tar.gz](copyrights.tar.gz) preserves the distribution's package notices and common license texts verbatim; [manifest.json](manifest.json) lists their hashes.

Ubuntu packages retain their individual licenses. Package source repositories are available at https://archive.ubuntu.com/ubuntu/ and https://ports.ubuntu.com/ubuntu-ports/; the installed `/var/lib/dpkg/status` records exact package versions. The cloud image's source packages are the matching Ubuntu Noble source packages, not this integration script. Ubuntu trademarks remain owned by Canonical; this is an independent toolbox integration.

The Linux kernel is Alpine's 6.6.142 virt kernel, not Ubuntu's distribution kernel. Alpine BusyBox 1.37.0-r20 and musl 1.2.5-r13 only bootstrap the root filesystem. Kernel/BusyBox/musl sources and package recipes are available from https://gitlab.alpinelinux.org/alpine/aports/-/tree/3.22-stable and https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.6.142.tar.xz . BusyBox is GPL-2.0-only, musl is MIT, and the Linux kernel is GPL-2.0-only with file-specific terms. The integration source archive includes the appliance build scripts; [sources.json](../sources.json) records dependency sources.

Local changes add UTF-8 environment settings, browser HTTP proxy configuration, virtio/9p support, interactive serial and text-screen sessions, terminal dimensions and screen synchronization, and disable cloud-specific startup services. No PowerShell package is installed in this Ubuntu image. System files run in RAM; complete VM snapshots preserve changes. Shared files are separately persisted by the toolbox.

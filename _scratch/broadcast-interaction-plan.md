# 直播工作台交互与效果

使用既有静态模块和 WebGL 合成器；开发材料仅留在本地和归档分支。

- [x] 几何模块：八方向缩放，旋转坐标系下固定对侧锚点；默认等比、Shift 自由；不允许负尺寸；鼠标与触摸使用 pointer capture，取消时还原。
- [x] 选区覆盖层：边缘热区、角点、旋转手柄，缩放时显示 X/Y 和 W/H；属性与预览实时同步；锁定、隐藏和麦克风不允许变换。
- [x] 效果模块：亮度、对比度、饱和度、色相、灰度、复古、反相、模糊；原图/黑白/复古/鲜艳/冷色/暖色预设，独立参数和重置，全部保存到工程。
- [x] 动画：每个素材选择无动画/淡入淡出，100–5000 ms；显示、隐藏、动画预览使用 GPU opacity，支持中途反向、隐藏结束停帧；工程只保存配置，不保存动画中的状态。
- [x] 渲染：滤镜在 WebGL shader 中执行，绿幕先抠像后调色；模糊采用固定数量采样，仅开启时计算；无效果时不引入 CPU 图像拷贝。
- [x] 快捷键：场景切换、新建、复制、重命名；素材选择、复制、锁定、显隐、移动、缩放、旋转、层级、居中、适配、删除；输入框、IME、模态框不触发；帮助收纳在问号按钮。
- [x] 验证：先写失败的几何/效果边界测试；浏览器真实拖拽、触摸、锁定、取消、旋转，像素验证滤镜和动画，实际录制解码；回归混音、推流轨道和自定义输出。
- [x] 发布：只上传直播工具运行文件；源码包更新归档分支，重新校验 manifest，部署 Pages 后检查线上资产与交互。

Pi browser integration

This tool includes @earendil-works/pi-agent-core and pi-ai 1.5.2.
Upstream: https://github.com/earendil-works/pi
Reference revision: 21e4cb80dddd4330806247818b1f4ec19af95fa5

The browser model adapter uses Pi's agent loop and event stream primitives.
local-ai-harness.mjs adapts the coding-agent compaction and transcript projection
strategy for a browser-local model. Terminal, process and filesystem tools from
the Node.js CLI are not included in this browser distribution.

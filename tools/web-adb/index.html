连接 Android 设备

  1. 在手机「关于手机」中连续点击版本号，开启开发者选项。
  2. 开启 USB 调试，用数据线连接电脑并解锁手机。
  3. 点击「连接设备」后选择手机，在手机上允许 RSA 调试授权。

需要桌面 Chrome / Edge 与 HTTPS。Firefox、Safari 暂不支持 WebUSB。Windows 如无法连接，请检查 Android USB 驱动；接口被占用时，请退出桌面 adb 或其他调试工具后重试。

调试密钥保存在此浏览器的 IndexedDB 中，用于下次认证；网站不会上传密钥。可清除此网站数据删除密钥，并在手机开发者选项中撤销 USB 调试授权。

终端会以设备的 shell 权限执行你输入的命令。中止操作会关闭 USB 连接，已传输的数据或已完成的安装不会撤销。

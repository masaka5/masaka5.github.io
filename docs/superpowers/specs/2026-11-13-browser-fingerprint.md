# 浏览器指纹

新增安全与认证工具，中文 Ant Design 页面。进入后只在当前浏览器采集本机特征，提供设备特征码、NeoPrint 浏览器指纹、稳定指纹；支持逐项明细、JSON 导出及跨浏览器手工导入对比。固定视口布局，移动端调整标识卡排列，长明细使用抽屉。

设备码根据规范化系统、图形设备、时区、触控信息计算，避开 WebGPU 支持差异、DPR、语言及渲染结果。保留原始 NeoPrint 跨浏览器 ID 供核查。不声称绝对唯一或所有浏览器完全一致；软件渲染、信息受限时不生成设备码。无后台自动采集、无指纹上传或后端身份库。

修正 NeoPrint 嵌套特征哈希缺失；适配 GPUAdapter.info，释放图形上下文，音频只离线渲染。特征不足、禁用 API、文件导入异常必须可恢复；导入报告只比较本地特征，导入 ID 不作为可信值。

执行：先验证嵌套哈希与归一化/导入/对比单测，再测试 Chromium、Edge、Firefox、缩放/刷新/移动布局、JSON 往返及限制环境，最后生成目录/SEO、源码许可和运行清单，验证发布容量与资源，部署并验证线上。

实测 Firefox 隐藏/替换 GPU 和触控字段，无法保证所有自动指纹跨引擎一致。
增加显式手动配对：创建随机 UUID，导出再由另一浏览器手动导入、确认关联。
配对码与指纹分开显示，localStorage 只存用户确认的配对码，可解除。

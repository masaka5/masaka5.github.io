# AI 助手代码块交互设计

## 目标

让 AI 助手在本地模型和接口模式下识别 Markdown 代码围栏，并把代码独立显示为可复制、可折叠的面板，同时保留普通文本、流式输出、历史记录和整段导出功能。

## 交互

- 识别标准代码围栏：```` ```语言\n代码\n``` ````，语言标识可为空。
- 每个代码块显示独立面板，包含语言标签、复制按钮和折叠状态。
- 代码块使用原生 `details` 交互，默认展开；用户可单独收起或展开。
- 含代码块的助手消息在消息头显示“隐藏代码/显示代码”按钮，一次收起或展开当前消息中的所有代码块。
- 未闭合的代码围栏在流式生成期间按普通文本显示，闭合后自动转换为代码面板。
- 复制代码只复制代码内容，不包含语言标签和界面按钮。
- 普通文本和代码均以安全 DOM 文本节点渲染，不执行模型返回的 HTML 或脚本。

## 结构

- 新增 `tools/ai/message-render.mjs`，提供纯文本分段和 DOM 渲染函数。
- `ai.js` 的本地流式渲染、接口流式渲染、历史记录渲染均调用同一渲染入口。
- 消息导出继续读取 `.message-body.textContent`，保证代码内容完整保留。
- 新增 `.code-block`、`.code-toolbar`、`.code-copy` 等局部样式，并沿用现有 AI 助手颜色、间距和移动端断点。

## 状态与边界

- 流式输出每次重绘时默认保持代码面板展开，避免在生成中引入复杂状态同步；生成结束后用户的折叠操作保持不变。
- 代码围栏内的反引号只在匹配闭合围栏时结束代码块；普通文本中的单个反引号保持原样。
- 不解析任意 HTML、链接或其他 Markdown 语法，降低渲染风险并控制改动范围。

## 验证

- 纯函数测试：无语言代码块、有语言代码块、多段代码块、未闭合代码块、代码中的反引号和普通文本。
- 浏览器验证：本地模式和接口模式各展示一段代码，逐段复制、单段折叠、全部隐藏/显示、流式更新和历史恢复。
- 回归验证：现有 AI 缓存测试、JavaScript 语法检查，模型 Worker 文件不变。

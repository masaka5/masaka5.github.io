# 5 GB 喷泉二维码实施计划

- [x] `fountain.mjs`：37 字节二进制头，CRC32、5 GiB 上限、128 源片分代，
  系统码/随机 GF2 方程和消元，先测试丢失乱序重复和 >4 GiB 边界。
- [x] `stream-package.mjs`、`disk.mjs`：1 MiB 压缩加密记录、WASM SHA256、
  OPFS 随机读写、IndexedDB 代快照，超限/配额检查及清理。
- [x] `fountain-worker.mjs`、发送接收页：进度回报、按需帧、循环新种子、
  未完成代补发、刷新恢复、导出，QR Byte+L，最高 2916 B 载荷。
- [x] 协议/实际 WASM/OPFS/相机解码/跨浏览器/布局/离线验证。
- [x] 精确打包与容量核查，部署后核对资源和线上往返（740ef5e4）。

运行中的 v2 互通。两端需更新到同版本。
